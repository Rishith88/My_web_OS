# My_web_OS
This is my first web Operating Sytem project. It is a cool project with a cyber[unk theme design which also sound scool

The idea was to make a desktop screen with wallpaper an  icon a windows kind of os  and a taskbar, just like a real OS.

## What it has

 Desktop:
 Cyberpunk wallpaper background
 Welcome message that fades out after 3 sec
 Live clock and date on the right side (IST time)
 Session timer on top navbar that counts from 00:00:00
 3 desktop icons - Calculator, Stopwatch, Calendar
 Taskbar at the bottom that shows which apps are open

Windows system:
 Click an icon to open the app in a window
 You can drag windows around by the titlebar
 Minimize, Maximize and Close buttons are there .
 Click taskbar icon to minimize / bring back the particualr window which sounds cool .
 Opened app shows "Open" badge on desktop icon which is way more convinient 

### 1. Calculator
Simple calculator but it very much functional .  It Can perform all the + - * / , and has AC to clear, Del to delete one digit,  and. for decimal. It is  made with a form and buttons.

### 2. Stopwatch
 It has the Start, Stop and Reset buttons with images. Shows HH:MM:SS. Counts every second.

### 3. Calendar
Mini calendar that shows todays date, day, month and year automatically. Updates every minute.

## Files in this project

`index.html` - It is the main file that comtorls most of the logic liek it uses ifram to open apps and basically all the stuff
  `calculater.html` - it is for the calculator app 
- `stopwatch.html` - it is for the stopwatch app
- `calendar.html` - it is for the calendar app


## How to run

This doesnt need the insatllation of anything 

1. Download / clone this repo
2. Just double click on `index.html` to open in browser
3. Or if using VS Code, right click index.html -> Open with Live Server


## How to use

- Click Calculator icon to open calculator, type numbers and press = 
- Click Stopwatch icon, press start button image to start
- Click Calendar icon to see todays date
- Drag window from top blue/black bar to move it
- Use the "-" button to minimize, square button to maximize, "X" to close
